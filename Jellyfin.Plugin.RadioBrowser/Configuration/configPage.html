Internet Radio

Stations come from radio-browser.info. Listeners find them under "Internet Radio" in the main menu and on the home screen. Saved changes are applied to all stored stations by the task "Refresh Internet Radio stations", which starts automatically.

Users who are not administrators need access to the channel: Dashboard → Users → user → Access, then turn on Enable access to all channels or tick Internet Radio.

Favorite stations

Shown in the Favorites folder, in this order. Every listener sees this folder. Leave empty to hide it.
Type at least two letters of the name, then press Search.

Listings

Two-letter code such as DE, NL or US. Adds a "Local stations" folder. Leave empty to hide it.
Most listened stations are listed first.
Opens lists of stations on the music page with Play and Shuffle, without the video filters of the standard folder page. Station logos are not shown in that list.
HLS stations always play through the server, which uses more server resources.

Playback

Sends only the station id. Keeps the directory's popularity rankings accurate.

Advanced

Leave empty to pick a server automatically. Set this only for a self-hosted mirror.
